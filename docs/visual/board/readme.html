Why

Without Suwageval

  • a prompt change ships after a few chats by hand
  • one red test: a real break or a dice roll?
  • "it worked last week" — on which prompt, model, data?
  • production failures stay in logs nobody reads
  • tests live in a notebook beside the agent

With Suwageval

  • every scenario runs several times on each change, in CI
  • each check has a history: regression, unstable or known
  • every run records the agent's version and data
  • real conversations are checked daily, a bad one becomes a test
  • scenarios are YAML in the agent's own repository
